# CBX Tools
CBX Tools is a utility program designed to assist in converting and optimizing common comic book file formats, including CBR, CBZ, EPUB and PDF. CBX Tools aims to preserve image resolution and DPI settings as much as possible, ensuring virtually lossless conversion and optimization for high-quality results.

# CBX Tools offers four main functions:

CBR/CBZ Optimization  –Optimizes CBR and CBZ comic book files by converting them into CBR files in RAR5 format with recovery records. Optionally, it optimizes JPEG images using the included jpegoptim or the external JPEGMini Pro. Note: WinRAR for Windows is required and not included. JPEGMini Pro is also not included. The user must own a valid license for both programs.

PDF to CBR/CBZ Conversion – Converts PDF files into CBR format.

EPUB to CBR Conversion – Converts image-only EPUB files into CBR format.

CBR/CBZ/EPUB to PDF Conversion – Converts CBR, CBZ, and image-only EPUB files into PDF format.

# Requirements
CBX Tools uses WinRAR for extracting and compressing CBR/CBZ/EPUB files, as it is the fastest application for ZIP extraction and RAR operations. Thererfore, WinRAR must be installed on the computer. Since it is not free software, it cannot be bundled with CBX Tools.

# Optional Requirements
CBX Tools can utilize JPEGMini Pro for JPEG optimizations. JPEGMini Pro must be installed separately, as it is not free software and cannot be included with CBX Tools.
